📚 Learning Management System (LMS) Backend

This is the backend service for a Learning Management System (LMS), built with Spring Boot and PostgreSQL, containerized using Docker and orchestrated with Docker Compose.

🚀 Features

RESTful API endpoints for LMS functionality

Database powered by PostgreSQL

Containerized using Docker

Easy local setup with Docker Compose

🛠️ Tech Stack

Java 17

Spring Boot

PostgreSQL

Docker & Docker Compose

Maven

⚙️ Setup & Installation
1. Clone the repository
git clone https://github.com/your-username/lms-backend.git
cd lms-backend

2. Build the application
mvn clean install

3. Run with Docker Compose
docker-compose up --build


This will start both:

App container → Spring Boot backend

DB container → PostgreSQL database
